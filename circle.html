Tonnetz: C major and its P, L, R neighbours

  • Rows: fifths. Down-right: major thirds, each one string row (red or blue stripe). Down-left: minor thirds.
  • ▽ major, △ minor. Every triad is 2 notes on one stripe + 1 on the next.
  • R C → Am: G → A, whole step, same row.
  • P C → Cm: E → E♭, half step, changes row.
  • L C → Em: C → B, half step, changes row.
